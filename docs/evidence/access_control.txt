# Access control proofs for the label-counts endpoint
# date: 2026-10-29T01:44:22+05:00  commit: 35d3343a6
# passwords replaced with *** in the commands below

## 1. No login
$ curl -s -i http://localhost:8080/api/annotation-analytics/tasks/1/label-counts
HTTP/1.1 401 Unauthorized
{"detail":"Authentication credentials were not provided."}

## 2. Logged in as 'outsider' (normal user, not owner/assignee of task 1, no organization)
$ curl -s -i -u outsider:*** http://localhost:8080/api/annotation-analytics/tasks/1/label-counts
HTTP/1.1 403 Forbidden
{"detail":"You do not have permission to perform this action."}


## 3. Admin, task that does not exist
$ curl -s -i -u admin:*** http://localhost:8080/api/annotation-analytics/tasks/999999/label-counts
HTTP/1.1 404 Not Found
{"detail":"No Task matches the given query."}
